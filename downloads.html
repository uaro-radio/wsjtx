The WSJT-X User Guide should always be your first source for help.  Use your browser's search facility to find a keyword or topic.

Downloads for Windows:

Installation instructions for Windows can be found in Section 4.1 of the WSJT-X User Guide.  

  • Windows 7 and later, 32-bit:   wsjtx-3.0.0-win32.exe
  • Windows 10 and later, 64-bit: wsjtx-3.0.1-win64.exe

Installation instructions for Linux can be found in Section 4.2 of the WSJT-X User Guide.  
  • Debian, Ubuntu, ... Intel/AMD:           wsjtx_3.0.1-linux-x86_64.deb
  • Debian, Ubuntu, ... ARM64:               wsjtx_3.0.1-linux-aarch64.deb
  • Fedora, RedHat ... Intel/AMD:            wsjtx-3.0.1.x86_64.rpm
  • Fedora, RedHat ... ARM64:                wsjtx-3.0.1.aarch64.rpm
  • Any 64-bit Intel/AMD Linux:                wsjtx_3.0.1-linux-x86_64.AppImage
  • Any 64-bit ARM Linux:                        wsjtx_3.0.1-linux-aarch64.AppImage
Downloads for macOS:

Installation instructions for macOS can be found in Section 4.3 of the WSJT-X User Guide.  
  • macOS with Apple Silicon:    wsjtx-3.0.1-arm64-macOS.pkg
  • macOS 10.15 through 15:     wsjtx-3.0.1-Darwin.dmg
